# Objectives

The objectives of the capstone project are:

1. Establish a controlled web application security testing environment.
2. Perform reconnaissance and service enumeration.
3. Assess the DVWA web application for representative vulnerabilities.
4. Demonstrate SQL Injection in a controlled environment.
5. Document the impact of the vulnerability.
6. Detect the simulated attack using server-side logs.
7. Analyze the root cause using application and source-code evidence.
8. Demonstrate containment and eradication.
9. Verify recovery after remediation.
10. Document the complete incident response process.
