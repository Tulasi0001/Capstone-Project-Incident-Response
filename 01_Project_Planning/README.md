# 01 – Project Planning

This folder contains the planning documentation for the ApexPlanet Cybersecurity & Ethical Hacking Internship Task 5 Capstone Project.

## Project

The capstone project focuses on a controlled web application penetration testing assessment of Damn Vulnerable Web Application (DVWA), followed by an incident response simulation based on the observed attack activity.

## Primary Security Scenario

The primary vulnerability investigated in this project is:

- SQL Injection (SQLi)

Supporting web application security scenarios documented from the earlier testing work include:

- Stored Cross-Site Scripting (XSS)
- Reflected Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)

## Project Objectives

The main objectives are:

1. Perform reconnaissance and service identification within the authorized lab environment.
2. Assess the DVWA web application for security vulnerabilities.
3. Demonstrate SQL Injection in a controlled environment.
4. Document the observed attack behavior and its impact.
5. Analyze web server logs associated with the simulated attack.
6. Perform an incident response simulation covering detection, analysis, containment, eradication, recovery, and verification.
7. Document mitigation and security recommendations.
8. Produce a final capstone report and demonstration.

## Scope

The assessment is limited to the intentionally vulnerable laboratory environment used for the internship.

The scope includes:

- DVWA web application
- Apache web server
- Database-backed web application functionality
- Authorized laboratory network
- Web server access logs
- Controlled vulnerability testing
- Incident response simulation

No external or unauthorized systems are included in the assessment.

## Lab Environment

The practical work was performed using a controlled virtual laboratory environment consisting of:

- Kali Linux – security testing and analysis workstation
- DVWA – intentionally vulnerable web application
- Apache – web server
- MariaDB/MySQL – database service
- VirtualBox Host-Only networking

## Tools and Technologies

The project uses:

- Kali Linux
- VirtualBox
- Nmap
- DVWA
- Apache
- MariaDB/MySQL
- Burp Suite Community Edition
- Linux command-line utilities
- Apache access logs

## Methodology

The assessment follows a structured workflow:

1. Project planning
2. Reconnaissance
3. Service enumeration
4. Vulnerability assessment
5. Controlled exploitation
6. Evidence collection
7. Incident detection
8. Incident analysis
9. Containment
10. Eradication
11. Recovery
12. Verification
13. Mitigation and recommendations
14. Final documentation
